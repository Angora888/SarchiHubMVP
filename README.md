# 🍽️ Sin Filas

Sistema web para la administración de restaurantes, diseñado para pequeños y medianos negocios.

Sin Filas permite gestionar productos, mesas, pedidos, cocina y caja desde una interfaz sencilla y moderna.

---

# ✨ Características

- 🔐 Inicio de sesión con JWT

- 🏪 Multi-restaurante

- 🍔 Gestión de categorías

- 🍕 Gestión de productos

- 🪑 Gestión de mesas

- 📱 Menú mediante código QR

- 📝 Pedidos con observaciones

- 👨‍🍳 Pantalla de cocina

- 💵 Pantalla de caja

- 📦 Estados del pedido

    - Pendiente

    - Preparando

    - Listo

    - Terminado

- 🔄 Actualización automática de pedidos

- 📊 Dashboard administrativo
